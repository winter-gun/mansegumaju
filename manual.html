만세구마쥬키우기 설명서

마음이 조마조마할 때, 고구마와 함께 숨을 고르고
자유롭게 낙서하는 작은 쉼터예요.

처음 한 번만 해두세요

  1. 받은 링크를 Safari(또는 크롬)에서 열어요.
  2. 우리만 아는 암호를 입력해요. 이 기기에서 처음 한 번만 물어보고, 다음부터는 바로 열려요. 기억이 안 나면 "힌트 보기"를 눌러요.
  3. 아이패드라면 공유 버튼(⬆︎) → "홈 화면에 추가"를 눌러두세요. 다음부터는 아이콘만 누르면 앱처럼 전체화면으로 열려요.
  4. 끝! 따로 설치하거나 결제할 것은 아무것도 없어요.

화면은 이렇게 흘러가요

앱을 열면 아롱이가 먼저 인사해요("잠깐 쉬어가자"). 잠시 후 저절로 메인 화면으로 넘어가고, 화면 가운데에서 고구마가 천천히 커졌다 작아졌다 하며 숨을 쉬어요. 화면 전체가 스케치북이라 어디든 바로 그리면 됩니다. 시간 제한도, 정해진 순서도 없어요 — 원하는 만큼 머물다 가면 돼요.

고구마 따라 숨 고르기

고구마가 커질 때 코로 천천히 들이쉬고, 잠시 멈췄다가, 작아질 때 입으로 길게 내쉬어요. 고구마 아래 글씨가 알려주니 그냥 따라가면 돼요.

들이쉬기 4초
멈춤 2초
내쉬기 6초

내쉬는 숨이 더 긴 이유: 길게 내쉴 때 몸의 긴장이 풀리는 스위치가 켜져요. 서너 번만 반복해도 달라지는 게 느껴질 거예요.

숨이 벅찬 날엔 ⋯ 메뉴 → 호흡 속도를 눌러보세요 — 짧게(3·1·5) → 보통(4·2·6) → 깊게(5·3·7) 순서로 바뀌어요. 고른 속도는 기억돼요.

그리기 도구

색 고르기

파스텔 다섯 가지 — 장미·풀·하늘·살구·코코아. 동그라미를 누르면 바뀌어요. 맨 끝 무지개 동그라미를 누르면 색상환이 열려요: 원을 돌려가며 색을 고르면(바깥으로 갈수록 또렷해져요) 어울리는 다섯 색이 아래에 함께 나와요. 비슷한 색 / 반대 색 / 세 갈래 / 한 색 농담 중에 고를 수 있고, "이 색들로 팔레트 바꾸기"를 누르면 툴바의 색 다섯 개가 통째로 그 팔레트가 돼요. 언제든 "처음 색으로"로 돌아올 수 있고, 이미 그려둔 그림의 색은 그대로예요.

펜

기본 도구예요. Apple Pencil로 그리면 누르는 세기에 따라 선 굵기가 살아나요. 손가락이나 마우스도 물론 돼요. 펜을 고르면 서랍 아래층에 부드러운 펜 · 연필(사각사각 흑연 질감) · 크레용(도톡한 왁스 질감)이 나와서 바로 고를 수 있어요.

마커

은은하게 비치는 굵은 펜이에요. 같은 곳을 여러 번 칠하면 조금씩 진해져서, 넓게 칠하거나 마음을 문지르듯 쓸 때 좋아요.

수채 브러시

물감이 종이에 스미듯 연하고 부드럽게 번지는 붓이에요. 같은 자리를 천천히 겹칠수록 은은하게 진해져서, 마음을 물들이듯 칠할 때 좋아요.

스탬프

누르면 발도장이 콩, 찍혀요. 손을 떼지 않고 끌면 총총총 이어져요 — 아롱이가 산책하는 것처럼요. 스탬프를 고르면 서랍 아래층에 발자국·하트·별·구름·고구마가 나와서 원하는 모양을 바로 고르면 됩니다.

지우개

문지른 자리만 지워져요. 다시 색 동그라미를 고르면 자동으로 그리기로 돌아와요.

스포이드

이미 그린 선을 톡 누르면 그 색을 그대로 집어와요. 이어서 그릴 때 "아까 그 색이 뭐였지?" 하고 헤맬 필요가 없어요. 색을 집으면 자동으로 원래 그리던 도구로 돌아옵니다. 겹쳐 칠해서 화면 색이 옅어져 있어도 처음 골랐던 진짜 색을 집어와요.

선 굵기

누르면 굵기 조절 미끄럼대가 떠요. 아주 가늘게부터 아주 굵게까지 원하는 만큼 조절할 수 있고, 위쪽에 실제 굵기가 미리 보여요. 그리기 굵기와 지우개 굵기는 따로 기억되어서, 굵게 칠하다가 지우개로 바꿔도 지우개는 지우개대로의 굵기를 유지해요.

다시 실행

되돌리기를 한 번 더 눌러버렸을 때 다시 살려내요. 되돌리기 옆의 오른쪽 화살표를 누르거나, 세 손가락으로 화면을 톡 두드려도 돼요. 새로 선을 그으면 되살릴 목록은 사라집니다.

⌃
도구 서랍 (아래 손잡이)

도구들은 평소엔 아래로 내려가 숨어 있어요 — 화면 전체가 종이가 되죠. 아래 가운데 작은 손잡이(⌃)를 톡 치면 스르륵 올라오고, 한 번 더 누르면 내려가요. 올라와 있을 때 그림을 그리기 시작하면 저절로 옅어지면서 손이 통과돼서, 도구가 있던 자리에도 그대로 그릴 수 있어요. 손을 떼고 잠시 지나면 다시 또렷해집니다.

서랍은 두 층이에요. 위층에는 색과 도구 여섯 개가 있고 자리가 절대 바뀌지 않아요 — 늘 같은 곳을 누르면 됩니다. 아래층에는 지금 고른 도구의 옵션만 나타나요: 펜이면 부드러운 펜·연필·크레용과 굵기, 스탬프면 발자국·하트·별·구름·고구마, 지우개면 지우개 굵기. 안 쓰는 옵션이 눈에 띄지 않으니 찾기가 쉬워요.

저장하기와 ⋯ 메뉴는 서랍 밖 오른쪽 위에 늘 있어요. 서랍을 열지 않아도 바로 닿습니다.

＋
확대·축소

오른쪽 아래 ＋ / − 버튼으로 100% → 150 → 200 → 300 → 400%까지 확대할 수 있어요. 가운데 숫자를 누르면 바로 원래 크기로 돌아옵니다. 두 손가락을 벌리거나 오므려도 되고, 두 손가락으로 밀면 확대된 그림을 옮겨볼 수 있어요 (두 손가락으로 톡 두드리는 되돌리기와는 헷갈리지 않아요). 확대는 돋보기처럼 보는 방식만 바꾸는 거라, 저장하거나 다시 보기를 하면 언제나 그림 전체가 담깁니다.

되돌리기

방금 그은 선 하나를 취소해요. 여러 번 눌러 계속 되돌릴 수 있어요. 두 손가락으로 화면을 톡 두드려도 돼요.

다시 보기

⋯ 메뉴 → 그림 다시 보기를 누르면 내 그림이 처음부터 천천히 다시 그려져요. 가만히 바라보기만 하면 돼요. 도중에 화면을 탭하면 바로 원래대로 돌아와요. 재생 중 아래의 🎥 영상으로 저장을 누르면 그려지는 과정이 타임랩스 영상 파일로 담겨요 — 아이패드에서는 공유 창이 떠서 바로 보낼 수 있어요.

아롱이 앨범

⋯ 메뉴 → 아롱이 앨범에서 사진을 한 장씩 넘겨볼 수 있어요 (옆으로 밀거나 화살표). "슬라이드쇼"를 누르면 호흡 리듬에 맞춰 저절로 넘어가고, "사진 추가"로 내 사진 보관함의 사진을 직접 넣을 수도 있어요 — 넣은 사진은 인사 화면과 "잘했어요" 화면에도 함께 등장해요. 직접 넣은 사진은 내 기기 안에만 저장돼요.

⋯
메뉴 (⋯ 버튼)

오른쪽 위 ⋯를 누르면 아래에서 쪽지처럼 올라와요. 뒤로 그림이 계속 보여서, 계절 효과나 고구마 꾸미기를 바로 확인하면서 고를 수 있어요. 바깥의 어두운 곳을 톡 치면 닫힙니다. 기능은 다섯 묶음으로 나뉘어 있어요 — 지금 쉬려고 / 그리기 / 모아둔 것 / 둘이서 / 꾸미기:

소리 — 한 곳에서 다 골라요: 빗소리 / 파도 / 피아노(호흡 따라 선율이 오르내려요)는 탭 한 번, 그 아래에서 내 소리(직접 녹음하거나 음악 파일 올리기, 내 기기 안에만 저장)도 담을 수 있어요. 기본은 꺼짐 · 새 장 넘기기 — 스케치북처럼 여러 장을 쓸 수 있어요. 장이 두 개 이상이면 왼쪽 위에 ‹ 1/2 › 표시가 생겨요 · 배경 사진 넣기 — 사진을 깔고 그 위에 그려요 (아롱이 사진 위에 왕관도!) · 꾸미기 — 고구마 꾸미기(밀짚모자·목도리·리본), 계절 효과(계절에 맞는 꽃잎·눈, 기본 꺼짐), 나만의 문구(저장 화면 인사말 직접 추가)가 한 칸에 모여 있고, 뒤로 그림이 보여서 바로 확인하며 고를 수 있어요.

보관함

저장하기를 누를 때마다 그림이 여기에도 차곡차곡 쌓여요. "다시 보기"는 그 그림을 그렸던 순서 그대로 천천히 재생해주고, "이어 그리기"는 그 그림을 캔버스로 불러와 계속 그릴 수 있게 해줘요. 불러오기 전에 그리던 그림은 자동으로 보관함에 먼저 담아줘서 사라질 걱정이 없고, 수정해서 저장하면 원본은 그대로 두고 새 그림으로 쌓여요. 보관함은 내 기기 안에만 있어요.

백업 — 보관함 아래 "내보내기"를 누르면 그림(직접 추가한 사진 포함)이 파일 하나로 저장돼요. 아이패드에서는 공유 창이 바로 떠서 카톡 "나에게 보내기"로 한 번에 보낼 수 있어요. 다른 기기에서 "가져오기"로 그 파일을 선택하면 그대로 복원됩니다. 보관함을 열면 마지막 백업이 며칠 전이었는지도 조용히 알려줘요.

☁ 동기화 — 보관함의 "☁ 동기화"를 누르면 두 기기의 보관함이 서로 맞춰져요. 저장할 때마다 클라우드에도 조용히 담겨서, 기기를 바꿔도 그림이 따라와요.

💌
우리 칸

⋯ 메뉴 → 우리 칸. 저장 화면의 "우리 칸에 보내기"나 보관함의 "보내기"를 누르면 그림이 서로의 기기에 도착해요. 받은 그림은 그렸던 순서대로 다시 보기도 되고 이어 그리기로 함께 완성할 수도 있어요. 새 그림이 와 있으면 앱을 열 때 💌 알림이 살짝 떠요.

✎
우리 일기

⋯ 메뉴 → 우리 일기를 누르면 달력이 떠요. 점이 찍힌 날 = 일기가 있는 날. 날짜를 누르면 그 날의 칸이 열리고, 서로 번갈아 이어 적는 교환일기가 돼요. 글은 사라지지 않고 날짜별로 차곡차곡 쌓여서 언제든 과거의 일기를 넘겨볼 수 있어요.

🎨
같이 그리기

⋯ 메뉴 → 같이 그리기를 켜면 둘이 같은 캔버스에 그려요 — 내가 긋는 선이 상대 화면에도 스르륵 나타나요. 상대의 선은 내 되돌리기로 지워지지 않아요. 둘 다 켜야 이어지고, 위의 작은 칩을 탭하면 꺼져요.

전체
전체 지우기

⋯ 메뉴 → 그리기 묶음 안에 있어요. 실수로 눌러도 괜찮게 두 번 눌러야 지워져요 — 한 번 누르면 "한 번 더 누르면 지워져요"라고 먼저 물어봐요.

저장
저장하기

내 낙서와 고구마가 한 장의 그림(PNG)이 돼요. 매번 다른 아롱이 사진과 다른 인사가 맞아줘요.

저장한 그림 간직하기

  1. 이미지 저장 버튼을 누르면 파일로 내려받아요. "엽서로"를 누르면 날짜와 문구가 얹힌 엽서 모양으로도 저장할 수 있어요.
  2. 아이패드에서는 미리보기 그림을 길게 꾹 누르면 "사진에 저장"을 고를 수도 있어요.
  3. 공유하기 버튼이 보이면 메시지·카톡 등으로 바로 보낼 수 있어요.

안심해도 되는 것들

  • 그리던 그림은 자동으로 두 군데에 저장돼요. 실수로 창을 닫거나 새로고침해도, 한쪽 저장이 잘못돼도 다시 열면 그대로 있어요.
  • 선이 저절로 사라지거나, 시간이 다 됐다고 끊는 일은 절대 없어요.
  • 소리는 기본적으로 꺼져 있고, 원할 때만 켜져요. 진동·알림은 없어요.
  • 한 번 열어둔 뒤에는 인터넷이 없어도 열려요 (홈 화면에 추가해두면 가장 확실해요).
  • 앱을 보는 동안에는 화면이 저절로 꺼지지 않아요.
  • 전부 무료이고, 광고나 결제가 생길 일도 없어요.
  • 내 그림은 내가 직접 보낼 때만 기기 밖으로 나가요 — 그리고 우리 칸·우리 일기·같이 그리기로 오가는 모든 내용은 암호로 잠근 채 올라가서, 암호를 아는 우리 둘만 열어볼 수 있어요.
  • 우리 칸·일기는 인터넷이 필요하지만, 없을 때 쓴 것도 연결되면 알아서 올라가요.
  • 아롱이 사진과 문구는 암호로 잠겨 있어서, 링크를 우연히 알게 된 사람은 열어볼 수 없어요.
  • 앱을 연 시각·횟수는 만든 사람에게 보여요. 그림·이름·위치 같은 건 절대 보이지 않아요.

뭔가 이상할 때

  • 예전 화면(색 4개)이 보여요 — 브라우저를 새로고침해 주세요. 그래도 그대로면 탭을 완전히 닫고 다시 열면 돼요.
  • 펜슬 굵기가 안 변해요 — Apple Pencil 배터리를 확인하고, 화면을 다시 터치해 보세요.
